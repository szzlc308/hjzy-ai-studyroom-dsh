# 慧教智研 · AI 自习室 / 互动课堂 / 互动白板 制作

把一个知识点做成**一节会讲课的课**：板书一笔一笔写出来，讲解一句一句跟着走；
学生随时举手打断、框选任意细节追问、答对检查点才继续；下课自动成笔记，1/3/7 天后复习叫你回来。

产出的成品是**单个 HTML 文件**：双击就能上课，断网可用，能拷给学生、能挂到平台、能塞进桌面端。

---

## 一、先定四件事（不写代码，先说清）

| 要素 | 取值 | 影响 |
|---|---|---|
| 主题 | 一句话，越具体越好（例："为什么利率下降时债券价格上升"） | 决定能否生成"论点式"板书，避免泛泛而谈 |
| 时长 | 8 / 12 / 15 / 20 / 25 / 30 / 35 / 40 / 45 / 50 / 55 / 60 分钟 | 决定步数与检查点数（见第三节） |
| 板书版式 | 自动判断，或指定 axis（坐标曲线）/ bars（柱状）/ flow（流程）/ taccount（T 型账户）/ compare（左右对比）/ note（便签） | 指错版式会导致"图与话不对应" |
| 授课层次 | 本科 / 高职 / 研究生 / 教师培训 | 决定术语密度与例子难度 |

**判定标准**：说得出"这一步要学生记住哪一句"，说不出来就是主题还太宽。

---

## 二、课时脚本：只写"讲什么"，不写坐标

脚本是 JSON，一步一屏（`frame: "replace"`，每步整屏替换，不累积残影）：

```json
{
  "title": "复利终值：时间为什么值钱",
  "subject": "财务管理 · 货币时间价值",
  "grade": "本科",
  "duration": "12 分钟",
  "meta": { "source": "ai" },
  "steps": [
    {
      "title": "提出问题",
      "narration": "先问一句：钱为什么会自己长大？把这个问题记住，后面每一步都在回答它。",
      "blocks": [
        { "type": "kicker", "text": "本课只解决一个问题" },
        { "type": "headline", "text": "钱为什么会自己长大？" }
      ],
      "ops": [ "…由排版器生成，不用手写…" ]
    }
  ]
}
```

**块类型（语义层，排版器负责落到像素）**

| type | 用途 | 关键字段 |
|---|---|---|
| `kicker` | 眉标（一行小字，说明这一步在干什么） | `text` |
| `headline` | 结论式一句话 | `text` |
| `bullet` | 要点（2–4 条，一条一行） | `items[]` |
| `formula` | 公式（框住强调） | `text`、`note` |
| `callout` | 易错点/结论（荧光笔底） | `text` |
| `figure` | 图形 | `figure: { type, ... }` |

**图形（figure.type）**

| type | 画什么 | 必填字段 |
|---|---|---|
| `axis` | 坐标曲线（趋势、均衡、贴现） | `xLabel`、`yLabel`、`points[]`、`caption` |
| `bars` | 柱状对比 | `labels[]`、`values[]`、`caption` |
| `flow` | 流程链路（3–5 步） | `steps[]`、`caption` |
| `taccount` | T 型账户 / 借贷方向 | `left`、`right`、`rows[]` |
| `compare` | 左右对照（概念 A/B） | `left{}`、`right{}` |
| `note` | 便签（待核实、补充说明） | `title`、`lines[]` |

**三条硬规矩**

1. **一步只做一个教学动作**：立问题 / 给要点 / 上公式 / 画图 / 框结论，五选一；
2. **每步 3–6 个块**，超过 6 个说明这一步该拆；
3. **讲解词 2–3 句、每句 ≤ 60 字**；讲解词会被切成句子，一句对应一组板书。

## 三、时长 → 步数 → 检查点

| 时长 | 步数 | 检查点 | 说明 |
|---|---|---|---|
| 8–15 分钟 | 5–7 | 1 | 一个机制讲透，不要贪多 |
| 20 分钟 | 7–9 | 1–2 | 机制 + 一个例子 |
| 25–30 分钟 | 9–11 | 2 | 导入—机制—例子—迁移—小结 |
| 35–45 分钟 | 10–12 | 2–3 | 每步一个动作，靠衔接句串起来 |
| 50–60 分钟 | 11–12 | 3 | 一节课上限；不追求面面俱到 |

**检查点规则（最容易做砸的一处）**

- 必须是**换参数的迁移题**：本步板书上的数字、结论**不能**直接当答案（否则学生只是抄写）；
- 必须能**当场判定**（单选 / 填空 / 借贷方向判断），不要开放问答；
- 答错给一句提示并**重播这一句**，不直接给答案。

正例：板书讲 8,000 元、5%、3 年 → 检查点问 10,000 元、4%、5 年，让学生算差额。
反例：板书算出 1,259.71 → 检查点问"复利终值是多少"。

## 四、书写节奏与讲解同步（v1.2.1 参数）

| 参数 | 值 | 说明 |
|---|---|---|
| 文字显现 | **148 ms/字**（下限 560 ms） | 太慢会让一屏写十几秒；太快学生读不完 |
| 一笔线条 | **长度 × 2.0**（夹在 460–2000 ms） | 长线不要一次画完，拆成 2–3 笔 |
| 虚线 | 1000 ms | 一条虚线画完再写标注 |
| 句间停顿 | 220 ms | 一句写完停一下，让眼睛跟上 |
| 这一句最短停留 | `500 + 222×字数` ms（≈4.5 字/秒的讲解语速） | 写完 + 念完 + 读够，才切下一句；**经验值，可按学段与课堂试看调整** |
| 倍速 | 0.6× / 0.8× / 1× / 1.3× | 0.6× 适合"边讲边板书"的慢课 |

> 参数说明：148 ms/字 ≈ 405 字/分（快于朗读），500 + 222×字数 是按讲解语速给的停留；两者都是**课堂实测的经验值**，不是标准，可按学段增减。

**同步判定法**：放一遍，问自己三句——
"讲到这句时，板书写到了吗？"（要一致）"写完停了吗？"（要停）"下一句是不是抢在写之前？"（不能抢）。

如果句子比书写快 → 减少这一句对应的算子，或把这句话拆成两句；
如果书写比句子慢 → 把这一步的图拆成两步（先画框架，再填数）。

## 五、成品自检（交付前逐条过，全部要过）

1. 每步整屏替换，没有上一步的残影叠在一起；
2. 文字没有压到图形，图没有压到字幕；
3. 一屏文字 ≤ 6 行、每行 ≤ 22 字（投影距离 8 米可读）；
4. 公式与数字用等宽字体，小数点对齐；
5. 检查点答案不出现在同屏板书里；
6. 讲完最后一步有收束句（今天只记住哪一条）；
7. 断网、双击打开能完整播放（不依赖 CDN）；
8. 手机竖屏能看（字幕不溢出、按钮不重叠）；
9. 控制台零报错（含"负数宽度"这类 SVG 报错）；
10. 讲解词不含学生个人信息，AI 生成的内容标注"待教师审核"。

## 六、常见失败与修法

| 症状 | 根因 | 修法 |
|---|---|---|
| 板书叠在一起糊成一团 | 步与步之间累积绘制 | 每步 `frame: "replace"`，整屏替换 |
| 字一到就全出来 | 用了"一次显示"而不是逐字裁剪 | 用 clipPath 从左到右裁（`148 ms/字`） |
| 字幕跑在板书前面 | 讲解按句子平均切时间 | 按"写完 + 念完 + 读够"推进（停留 = 500 + 222×字数 ms） |
| 图挤成一条线 | 左文右图各占一半却没给最小值 | 无图时正文占满宽；有图时右栏 ≥ 420px |
| 讲一半卡住 | 某一步的算子数过多（>12） | 拆步，不要把 20 个算子塞一起 |
| 投影看不清 | 字号按屏幕设，不按投影距离设 | 正文 ≥ 30px（1280×720 画布），标题 ≥ 46px |
| AI 生成"面面俱到" | 提示词没限步数 | 按时长给步数区间，并要求每步只做一件事 |

## 八、与平台的关系（可选）

- 平台侧：`/whiteboard`（AI 自习室）支持 `?topic=`、`?autogen=1`、`?minutes=` 深链，可直接生成并上屏；
- 知境侧：知识图谱点节点 →「在 AI 自习室学这一节」，带入课程上下文；
- 学习记录：`/api/study/me|shelf|progress|discussion`（登录后按账号落盘，未登录只存本机）。

> 本技能只负责"把课做对"；学术口径、税务/准则表述仍须教师按本校教材与现行规定核对后使用。

## 九、语音讲解（v1.2.1 起）

- **默认行为**：点「开始讲课」自动开启语音（浏览器要求先有用户点击才允许发声），按钮显示当前音色；
- **音色挑选**：按 `zh-CN` 优先，优先 Huihui / Xiaoxiao / Yaoyao；**不要**用系统默认音色（常为 en-US，念中文会怪腔）；
- **无中文语音包**：不要静默失败——提示用户到「Windows 设置 → 时间和语言 → 语音」添加中文，并自动退回字幕模式；
- **同步**：语音与书写共用同一句节奏（`dwell = 500 + 222×字数`），念完才写下一句；
- 语音用本机合成（离线、不上传）；`speechSynthesis.getVoices()` 可能异步加载，需等一次 `voiceschanged`（≤1.5 秒）。

## 十、配套能力（书架 / 讨论室 / 学习记录 / 系统学习 / 返回首页）

| 能力 | 要点 |
|---|---|
| 书架 | 列出内置/AI 生成/自建课时，显示进度与上次时间；「继续学习」跳到上次那一步 |
| 讨论室 | 接平台大模型作答并标注来源；未登录/离线降级为本课知识卡 |
| 学习记录 | `GET /api/study/me|shelf`、`POST /api/study/progress|discussion`；按账号落盘，未登录 401 → 前端显示"仅本机保存" |
| 系统学习 | 左侧入口直达知境知识图谱（内网 http://<host>:8151/#/graph（访问日期：2026-11-23），公网 https://xxzx.zgzk.me/#/graph（访问日期：2026-11-23（访问日期：2026-11-23））），看完结构点节点回来自习 |
| 返回首页 | 顶栏「返回首页」回展示首页（内网 `:7200`，公网 `www.zgzk.me`）；离线单文件不显示，避免死链 |

**验收要点**：语音在无中文包时给提示（不静默）；书架进度能续上；讨论记录能回看；`file://` 模式零控制台错误。
