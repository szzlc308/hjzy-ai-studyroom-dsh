# 语义块与版式协议（v1.2）

## 1. 为什么只写语义块

模型不擅长算坐标：一算就重叠。所以脚本只写"这一步要出现什么"（块 + 版式），
由排版器按固定网格落地：左边文字列、右边图形列、自动换行、不出边界。

## 2. 块字段全集

```ts
type Block =
  | { type: 'kicker';  text: string }                       // 眉标，一行
  | { type: 'headline'; text: string }                      // 结论句，一行
  | { type: 'bullet';  items: string[] }                     // 2–4 条
  | { type: 'formula'; text: string; note?: string }         // 公式，框住
  | { type: 'callout'; text: string }                        // 荧光笔底
  | { type: 'figure';  figure: Figure }                      // 六种图之一
```

## 3. Figure 字段

```ts
type Figure =
  | { type: 'axis';    xLabel: string; yLabel: string; points: [number, number][]; caption?: string }
  | { type: 'bars';    labels: string[]; values: number[]; caption?: string }
  | { type: 'flow';    steps: string[]; caption?: string }
  | { type: 'taccount';left: string; right: string; rows: { left?: string; right?: string }[] }
  | { type: 'compare'; left: { title: string; lines: string[] }; right: { title: string; lines: string[] } }
  | { type: 'note';    title: string; lines: string[] };
```

## 4. 校验规则（排版器会拒绝的写法）

- `headline` 超过 24 字 → 折成 `headline` + `bullet`；
- `bullet.items` 超过 4 条 → 拆步；
- `points` 少于 3 个 → 画不出趋势，改 `compare`；
- `flow.steps` 超过 5 个 → 拆两步（前半 / 后半）；
- 一个步里 `figure` 只能有一个；两个图分两步画。
