# 播放引擎接口（单文件自习室）

页面把能力挂在 `window.HJWB_CORE`（动作）与 `window.HJWB_STATE`（状态）上。

## 常用动作

| 接口 | 作用 |
|---|---|
| `loadLesson(index)` | 载入第 index 个课时（0 起） |
| `prepare(lesson)` | 预处理：切句、分组、算时长（导入外部 JSON 前先调用） |
| `gotoStep(idx, play)` | 跳到第 idx 步；`play=true` 开始讲 |
| `renderInstant(idx)` | 立即渲染到第 idx 步（不放动画） |
| `playPause()` | 播 / 停（暂停从当前句子继续） |
| `replayStep()` | 重播这一步 |
| `setSpeed(v)` | 0.6 / 0.8 / 1 / 1.3 |
| `setSubtitle(text, animate)` | 直接改字幕（调试用） |
| `answerQuestion(q)` | 用本课知识卡回答（离线降级） |

## 事件（`window` 上的 CustomEvent）

| 事件 | detail | 时机 |
|---|---|---|
| `hjwb:step-complete` | `{ lesson, step, title }` | 一步讲完（含笔记落盘） |
| `hjwb:checkpoint-open` | `{ lesson, step }` | 打开检查点 |
| `hjwb:lesson-open` | `{ lesson }` | 切换课时 |

## 深链参数

| 参数 | 作用 |
|---|---|
| `?topic=…` | 预填 AI 成课主题 |
| `?minutes=60` | 预填时长（8–60） |
| `?autogen=1` | 打开即自动生成并采用 |
| `?ai=1` | 打开 AI 成课面板 |

## 学习记录接口（平台版）

| 接口 | 说明 |
|---|---|
| `GET /api/study/me` | 学习档案（书架 + 笔记 + 讨论） |
| `GET /api/study/shelf` | 书架（按最近学习排序） |
| `POST /api/study/progress` | 上报进度 `{lessonId,title,step,total,note?}` |
| `POST /api/study/discussion` | 存一条讨论 `{lessonId,q,a,source}` |

未登录返回 401 + `LOGIN_REQUIRED`；前端应降级为"仅本机保存"，不要报错弹窗。
